# BUKO — بوكو

تطبيق Flutter لسوق السيارات المستعملة في السودان، بواجهة عربية RTL.

## التشغيل

```bash
flutter pub get
flutter run
```

## إنشاء APK

```bash
flutter build apk --release
```

## ما تم تجهيزه

- واجهة BUKO عربية RTL.
- بحث عن السيارات والتنقل بين أقسام التطبيق.
- المفضلة وإدارة الإعلانات بشكل تجريبي.
- لوحة تحكم إدارة داخل التطبيق لمراجعة الإعلانات ومراقبة الإحصائيات.
- GitHub Actions لبناء APK تلقائياً عند الدفع إلى `main` أو تشغيل Workflow يدوياً.
- المشروع الآن موجود كملفات Flutter فعلية في جذر المستودع، وليس داخل ZIP فقط.

## ملاحظة مهمة

لوحة الإدارة الحالية هي واجهة UI تجريبية وليست نظام صلاحيات حقيقياً. قبل الإطلاق يجب ربطها بـBackend وقاعدة بيانات ومصادقة آمنة، مع صلاحيات Admin على الخادم وعدم وضع كلمات مرور داخل التطبيق.
