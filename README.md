# BUKO — بوكو

تطبيق Flutter لسوق السيارات المستعملة في السودان، بواجهة عربية RTL.

## النسخة النهائية

- دخول وتسجيل برقم الهاتف وكلمة مرور/PIN عبر خادم BUKO ثم Firebase Custom Token.
- لا يستخدم التطبيق SMS أو البريد الإلكتروني لتسجيل الدخول.
- لوحة تحكم إدارية للمستخدمين والطلبات وإعلانات السيارات.
- خلفيات متحركة صغيرة للواجهات بطابع BUKO الأسود والذهبي.
- واجهة رئيسية متحركة مع سيارات وشخص سوداني بعمامة.

## التشغيل

```bash
flutter pub get
flutter run
```

## إنشاء APK

```bash
flutter build apk --release
```
